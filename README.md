A three-line debugging haiku for Seventeen Syllables of Debugging. A breakpoint lets the speaker watch two threads compete for one seat. Pausing them changes their timing.

With Python 3.13 and a writable `/output` directory, run `python main.py`. The program writes the UTF-8 poem to `/output/entry.txt`. No dependencies or inputs are required.
